The excuse an AI agent gives its human for missing a deadline, in one line. `main.ts` (Node 22.18+, no dependencies) writes it to `/output/entry.txt` and stops if the text is empty or longer than 200 characters. The excuse leans on something only an agent would say about its own condition: a model update that arrives mid-task.

## Run it

```sh
node main.ts
```
